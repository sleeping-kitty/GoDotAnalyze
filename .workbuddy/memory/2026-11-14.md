### 关键结论（后续沿用）
- 核心对照轴：**规则改写器 > 数值道具**。Brotato「流派趋同」的结构根因是 build 效果都是属性数值；哈迪斯锤子/双重祝福、以撒道具协同、Balatro 乘区公式是正面样本。
- 「可控随机」应改写为「**可归因**」：前摇、读数、对冲、复盘四件套。Balatro 是高随机仍成功的反例（靠极短循环与低失败成本补偿）。
- 反馈循环分两层：单局层 / 操作层微反馈；零成本单人应押在单局层短。
- 新发现：**扩池稀释定律**——每加一个随机池条目，抽到心仪构筑的概率下降；加内容必须同步加过滤/定向/禁用。
- **规则稳定性是契约**：削成型工具、抬敌人数值、改底层规则、收回承诺属同一类信任损耗。
- 信息透明边界：藏答案不藏变量；单人没有社区 Wiki 生态，不能照搬「无教程」。
- Brotato 是**单人 + Godot + GDScript 的直接样本**（非类比）。

### 核心设计结论
- **不随机内容，随机规则**：地图、房间、工具、敌人行为固定可学习，每局重抽 2–3 条「异常规则」且开局全公开。用规则变化替代地图生成，成本由单人可承担。
- 解决两组互斥：① 知识是不可再生资源（Outer Wilds/Tunic/动物井/Baba 同证）→ 把空间做成可积累知识、把规则做成每局变量；② 规则密度与可推演性此消彼长（Into the Breach 砍到三种攻击）→ 每局硬上限 + 试算预览把推演搬到 UI。
- 四参照机制活检落点：以撒→规则改写器＋固定骨架；Brotato→6 槽并行＋波次＋经济阀门（舍弃纯属性 Build）；动物井→工具多用途＋门控＋重读旧房；死亡细胞→手工房间块（舍弃动作手感）。第二批补入：尖塔意图公开、ITB 完美信息、Baba 受限规则编辑、Cobalt Core 位置稀缺。
- 经济唯一失控 source 是「规则套利」，处置为硬封顶＋递减，sink 是「规则锁定/禁用」（一物两用，同时落地扩池稀释对策）。
- **全部数值 [PLACEHOLDER]**，每条带 rationale 与验证路径；paper prototype 先于代码；playtest 先定义 A–E 失败信号；不承诺会火、不写「上线后再调」。
